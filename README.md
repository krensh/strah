# HOT POTATO

Многопользовательская аркадная игра для двух ноутбуков в локальной сети.

## Описание
Игроки подключаются друг к другу, чтобы перекидывать «горячие» предметы. 
Если картошка или бомба останется у тебя до конца таймера — ты теряешь HP. 
Кто первый потеряет все жизни — приносит очко сопернику. Игра бесконечная.

## Технологии
- **Frontend:** TypeScript, React, Vite.
- **Backend:** Rust, Tauri, TCP-сокеты, mDNS (авто-поиск хоста).
- **Стиль:** Ретро-аркада 2000-х, пиксельная графика.

## Как играть
1. Запустите приложение на двух устройствах в одной Wi-Fi сети.
2. На первом — «Создать игру» (Хост). На втором — «Подключиться» (Клиент).
3. Клиент вводит IP хоста (показывается на экране) или использует авто-поиск.
4. Кликайте по предметам, чтобы перекинуть их сопернику!

## Особенности
- Синхронизация состояния в реальном времени.
- Разные типы предметов (картошка бьёт по 1 HP каждые 2 сек, бомба взрывается на 30 HP).
- Бесконечные раунды со сбросом HP и накоплением очков.
